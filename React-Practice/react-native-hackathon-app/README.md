# React Native Hackathon App

## Overview
This project is a React Native application developed for a hackathon. It serves as a template for building mobile applications using React Native and TypeScript.

## Getting Started

### Prerequisites
- Node.js (version 14 or later)
- npm or Yarn
- React Native CLI
- Android Studio or Xcode (for mobile development)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   cd react-native-hackathon-app
   ```

2. Install dependencies:
   ```
   npm install
   ```
   or
   ```
   yarn install
   ```

### Running the Application
To run the application on an Android or iOS simulator, use the following commands:

- For Android:
  ```
  npx react-native run-android
  ```

- For iOS:
  ```
  npx react-native run-ios
  ```

### Folder Structure
- **src/App.tsx**: Main entry point of the application.
- **src/components**: Contains reusable components.
- **src/screens**: Contains screen components.
- **src/navigation**: Contains navigation setup.
- **src/hooks**: Contains custom hooks.
- **src/services**: Contains API service functions.
- **src/store**: Contains state management setup.
- **src/types**: Contains TypeScript types and interfaces.
